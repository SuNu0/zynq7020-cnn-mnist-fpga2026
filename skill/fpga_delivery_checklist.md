# 可复用FPGA交付踩坑清单

| 触发条件或观察 | 排查与处理 | 失效边界 |
|---|---|---|
| 同一成绩出现于软件、仿真和实板宣传 | 分别记录数据规模、执行后端、接口与时间窗口 | 日志真实来源仍需人工确认 |
| 换模型后板上表现不变 | 核对mem、BIT、ELF与固件版本；修改部署权重后重新综合下载 | 文件一致不能证明新时序已闭合 |
| 输入间断或结果消费变慢 | 检查valid/ready、背压、复位与连续帧测试 | 正常连续输入PASS不覆盖这些条件 |
| 精简包后某个cmd打不开 | 逐个核对启动器目标图片、脚本、模型；不要仅解压测试 | 静态路径存在不证明外部工具可用 |
| 源码包含旧版本模块 | 显式选择当前top和权重；保留许可与贡献来源 | 不要将第三方版权改成自己的MIT声明 |
| 路径在本机可用、换机失败 | 改用相对ROOT与英文文件名；外部工具路径用环境变量 | 板卡不同仍须核对引脚、时钟、DDR和供电 |
| 数据很大而仓库下载不全 | 固定Release资产、SHA256、解压目录与恢复脚本 | 上游数据下线时需保留合法镜像或随包压缩源 |
| 加速器很快而网页响应慢 | 分开测预处理、传输、进程启动、DMA与计算窗口 | 周期折算不等于整机实测性能 |

来源为当前会话已观察的预览入口遗漏、数值边界检查、版本匹配说明及V3既有接口验证记录。方法可迁移到其他FPGA任务，具体结果不能迁移。
