# FPGA交付与数值核验技能包

该目录独立于CNN网络，可复用于采用RTL/HLS/PS的其他工程。它沉淀自本次AI协作和交付检查，不是PYNQ专项Skill，也不主张PYNQ加分。

## 1 SHA256交付校验

- 适用场景：发布源码、BIT、ELF、测试向量时确认文件齐全且未变。
- 用法：`python skill/verify_manifest.py manifest/files.csv --root .`；也可给其他项目的CSV（relative_path,sha256两列即可）。
- 已验证效果：当前工程全清单通过；临时样例中删除文件、改动字节、目录逃逸路径均能失败退出，详见report/publication_validation.json。
- 观察来源：压缩包解压成功并不能说明缺文件或不同版本混用，须对部署和参考文件逐项校验。
- 失效条件：清单与文件同时被恶意替换不能被证明；清单正确也不能证明电路功能正确。数据外置时须另核验data/dataset_manifest.csv。

## 2 通用十六进制数值比对

- 适用场景：RTL导出的mem与黄金参考逐值比对，支持固定位宽补码。
- 用法：`python skill/compare_mem.py reference.mem actual.mem --bits 16 --signed`。返回0表示一致，非0表示不一致或格式错误。
- 已验证效果：对本项目75组池化/分数/类别向量进行参考重算和比对；同时对临时差异样例验证失败行为。
- 观察来源：只看最终类别可能漏掉中间溢出或舍入差异。
- 失效条件：该工具做严格逐值比较，不允许容差；不同布局或符号约定需先标准化，不适用于直接比较浮点文本。

## 3 英文路径与交付入口检查

- 用法：`python skill/check_paths.py .`。标准README.md、LICENSE按指南示例允许，其余路径使用小写英文、数字、下划线、连字符及扩展名点。
- 观察来源：中文文件名、大小写不一致和已删除图片仍被启动器引用，都会破坏跨平台或双击入口。
- 边界：文件名符合约束不代表所有程序都跨平台，本工程默认演示仍依赖Windows与Xilinx安装。
